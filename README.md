DiabPredict

An explainable diabetes prediction web application built with Django and Machine Learning.

Features

- Diabetes / non-diabetes prediction
- Logistic Regression, Decision Tree & Random Forest comparison
- Probability and risk assessment
- SHAP-based prediction explanations
- Interactive model analytics with Plotly
- Prediction history using SQLite

 Tech Stack

Python, Django, Scikit-learn, Pandas, NumPy, SHAP, Plotly, SQLite, HTML, CSS, Bootstrap

 Dataset

Pima Indians Diabetes Dataset.

 Disclaimer

This project is for educational and research purposes only and is not a medical diagnostic tool.
