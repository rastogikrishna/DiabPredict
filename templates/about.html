About DiabPredict

About DiabPredict

DiabPredict is an explainable machine learning web application that estimates diabetes risk from eight patient health features using a trained classification model.

How DiabPredict Works

  1. User enters patient information
  2. Input validation and preprocessing
  3. Machine learning prediction
  4. Diabetes probability calculation
  5. Risk classification
  6. SHAP-based explanation
  7. Result and model interpretation

Model

DiabPredict trains and compares the following classifier models on database records to find the highest-performing pipeline:

  • Logistic Regression
  • Decision Tree
  • Random Forest

The models are evaluated using stratified cross-validation metrics. Currently, the selected best-performing model integrated into the pipeline is Logistic Regression.

Explainability

DiabPredict uses SHAP (SHapley Additive exPlanations) values to calculate and display the game-theoretic contributions of each metric. This shows exactly which patient features contributed most strongly toward or away from the model's diabetes prediction.

Features Used
  • Pregnancies
  • Glucose
  • Blood Pressure
  • Skin Thickness
  • Insulin
  • BMI
  • Diabetes Pedigree Function
  • Age
Technology
Python Django Pandas NumPy Scikit-learn SHAP Plotly SQLite Bootstrap
Medical Disclaimer
